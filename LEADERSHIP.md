# Excel для кабинета руководителя

Отдельный `LEADERSHIP_REPORT_KEY` (32+ случайных символа) открывает только API отчётов. Пустой ключ отключает интеграцию. Ключ не позволяет создавать/обрабатывать заявки или пользоваться административными функциями бота.

`GET /api/leadership/v1/catalog` возвращает периоды. `POST /api/leadership/v1/report` принимает `{fromUtc, toUtc, timeZone, filters:{}}`. Начало включается, конец исключается и ограничивается текущим временем. Для диапазона максимум 366 дней; `fromUtc:null` означает всю историю. Даты должны содержать часовой пояс.

Все запросы требуют `Authorization: Bearer <ключ>`. На одном VPS используйте loopback; между серверами — HTTPS. Ответ ZIP содержит report.xlsx, prompt.txt и manifest.json версии 1. Cache-Control: no-store. Код 401 означает неверный ключ, 404 — интеграция отключена, 413 — превышен размер, 422 — неверный запрос, 429 — другой отчёт ещё строится, 503 — API сайта недоступен.

Генератор app/statistics.py и каталог администраторов используются повторно. Бот обращается к подписанному API сайта, передавая обе границы периода. Общая блокировка с обычной административной выгрузкой ограничивает нагрузку. Промпт — resources/leadership-prompt.txt; он учитывает старую неполную историю и различие фактического исполнителя и ответственного.

Дополнительная миграция сайта или SQLite не требуется. Существующие выгрузки и webhook сохраняются. Контракт и настройки нового бота: Studio313-krd/lk-batagov-bot, docs/ARCHITECTURE.md. Проверка: `python -m pytest tests/test_leadership.py tests/test_site_client.py -q`.
